# Label Filer

端末内の画像・文章ファイルを一覧にし、タグで探せるWindows向け整理ツールです。画像への自動タグ付け、文章からの語句抽出、タグ編集・絞り込み、名前変更・移動などを備えています。

## 起動

Windowsで `start.bat` をダブルクリックします。初回はPython 3.14、必要な部品、約1GBの画像認識モデルを取得するため、インターネット接続と空き容量が必要です。モデル取得後の画像処理は端末上で行います。

Python 3.14がすでにある場合は、次の方法でも起動できます。

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app\main.py
```

画像認識には `MiaoshouAI/Florence-2-base-PromptGen-v2.0` を使用し、取得版をソース内で固定しています。初回はこのモデルのコードも取得します。使用条件は提供元を確認してください。

## 公開版の内容

- 実際の画像・文書、利用したフォルダの履歴、データベース、モデル本体、実行用の加工済み部品は含めません。
- 大規模な外部由来タグ辞書を外し、自作の小さな見本辞書を `data/` に配置しました。日本語訳・分類は見本に含まれる語だけです。タグの手動登録とモデルによる自動タグ付けは利用できます。
- `data/tag_dictionary.csv` は `english,japanese` の2列、`data/danbooru_20250919.csv` はタグ名・分類番号・件数・別名の4列です。後者のファイル名は既存処理との互換性のため保持していますが、内容は独自の見本です。
- アプリが生成する利用履歴は `data/app_settings.json`、各ライブラリの情報は選んだ保存場所に残ります。
